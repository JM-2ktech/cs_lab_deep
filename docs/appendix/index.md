# 부록 🧰

Agent Builder와 Copilot Studio를 다루는 보충 자료입니다. **과정 본문과 독립된 문서라 순서 없이 골라 볼 수 있습니다.** 필요한 준비물은 아래 표의 「준비」 열과 각 페이지의 「준비」 절에 있습니다.

부록은 성격이 둘로 나뉩니다.

### 제품을 더 만져 본다

Copilot Studio의 조작을 직접 해 봅니다.

| 부록 | 분 | 준비 | 무엇을 보나 |
|---|---|---|---|
| [내 에이전트를 Copilot Studio로 가져가기](./to-copilot-studio.html) | 10 | Agent Builder 에이전트 | 같은 에이전트가 도구를 바꾸면 무엇이 달라지는가 |
| [에이전트가 에이전트를 부른다](./connected-agent.html) | 30 | 지식 문서가 있는 Copilot Studio 에이전트 · 웹사이트를 지식으로 쓰는 Copilot Studio 에이전트 | 두 에이전트를 도구처럼 부르고, 설명 하나로 경로를 바꾸기 |

### 왜 그런지 이해한다

조작보다 **판단**을 다룹니다. 다른 도구로 옮겨 가도 남는 이야기라, 수준이 높은 차수에서 값이 큽니다.

| 부록 | 분 | 준비 | 무엇을 보나 |
|---|---|---|---|
| [에이전트 안에서 일어나는 일](./inside-the-agent.html) | 5+10+10 | 지식 문서와 지침이 있는 Copilot Studio 에이전트 | RAG·인덱싱 · 토큰과 비용 · 문서가 답을 정한다 |
| [지침을 어떻게 쓰는가 — 마크다운과 구조](./instructions-markdown.html) | 15 | 지침이 있는 Copilot Studio 에이전트 | 지침을 마크다운 구조로 쓰는 이유. 근거가 있는 말과 없는 말 |
| [모델을 바꾸면 같은 지침이 다르게 지켜진다](./model.html) | 20 | 지식 문서와 지침이 있는 Copilot Studio 에이전트 | 지침은 같은데 답이 갈린다. 근거 표시가 거짓인 경우 |
| [읽어 오는 양 — 1,000행짜리 표를 붙이면](./read-volume.html) | 20 | Excel 행 나열 도구가 붙은 Copilot Studio 에이전트 | 전부 오지 않는다. 그런데 그 사실이 안 드러난다 |

{: .note }
**뒤쪽 넷은 Copilot Studio를 안 쓰게 되더라도 남습니다.** 근거를 어디서 찾을지, 지침을 어떻게 쓸지, 모델이 무엇을 정하는지는 도구가 바뀌어도 같은 질문입니다.

{: .note }
**「에이전트 안에서 일어나는 일」은 세 부분을 따로 볼 수 있습니다.** 1부(RAG·인덱싱)는 지식 문서를 올린 뒤 인덱싱을 기다리는 5~10분 동안 읽는 분량입니다. 2부(토큰·비용)는 토크나이저를 직접 돌려 보는 15분 실습이고, 3부(문서 준비)는 10분이면 읽습니다.

{: .warning }
**「지침을 어떻게 쓰는가」·「모델을 바꾸면」·「읽어 오는 양」은 끝나고 반드시 되돌려 놓으세요.** 모델과 지침을 바꾼 채로 두면 에이전트가 부록을 시작하기 전과 다른 조건에서 답합니다. 지침은 시작하기 전에 원문을 복사해 둡니다.
